## 🚀 How to Run

### Quick Start (3 steps)

```bash
# 1. Navigate to directory
cd react-version

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Then open **http://localhost:5173** in your browser!

### Production Build

```bash
npm run build      # Create optimized build
npm run preview    # Preview production build
```
